# Data Challenge

Ten wpis pokazuje format dla konkursu lub hackathonu, w którym najważniejsze są dane, eksperymenty i wynik.

## Wyzwanie

Opisz dataset, zadanie konkursowe i główną metrykę sukcesu.

## Podejście

Wpisz kroki analizy, dobór cech, eksperymenty i najważniejsze iteracje.

## Stack

- Python
- Analiza danych
- Walidacja wyników
- Raportowanie

## Wynik

Dodaj miejsce, wyróżnienie albo wnioski z feedbacku.
