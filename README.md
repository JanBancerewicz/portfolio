# Developer Portfolio Scaffold

Minimalistyczny scaffold lokalnej strony portfolio programisty, studenta informatyki i entuzjasty hackathonow.

## Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- lucide-react

## Uruchomienie lokalne

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Struktura

```text
src/
  components/
    layout/
    sections/
    ui/
  data/
  App.tsx
  main.tsx
  index.css
```

Treści w sekcjach sa placeholderami. Docelowe dane mozna podmieniac w plikach `src/data/*.ts` oraz komponentach sekcji.
